01 / PROBLEM

Research Question

Can the system maintain a consistent global ID when someone leaves and re-enters the frame or appears on another camera?

A single-camera tracker links people across nearby frames. Associating identities across track fragments or cameras also requires comparing appearance features. Similar clothing, distance, occlusion, and overlapping people make that comparison harder.

This project also studies the open-set setting: a person may be absent from the existing gallery, so the system must decide whether to reuse a known ID or create a new one.

02 / SYSTEM

Implemented System Pipeline

Video / StreamYOLO DetectionByteTrack TracksCLIP-ReID FeaturesGallery Global ID
  • YOLO detects people, and ByteTrack links their detections across consecutive frames within each camera into local tracks.
  • CLIP-ReID extracts features from person crops that need an identity decision. The system compares them with gallery features to reuse a global ID or assign a new one.
  • The two-camera pipeline shares one gallery and one set of global IDs. Single-camera tracking evaluation and cross-camera functionality are validated separately.

I have also tried OC-SORT, different Re-ID update frequencies, and supplementary ArcFace checks. The analyses below include only experiments with clearly defined scope and results.

03 / TRACKING EVALUATION

Local and Global ID Evaluation

I compared ByteTrack local IDs and CLIP-ReID v2.5 global IDs from the same run against 2,661 manually annotated frames. Global IDs improved identity association metrics, while detection accuracy declined because some detections were absent from the global output.

05 / GALLERY

Overlapping People and Gallery Contamination

When people overlap, a crop may include part of another person. Using that crop to update the gallery can gradually shift the stored identity feature.

06 / NEXT

Current Direction

I am continuing the cross-camera tracking and open-set Re-ID work, with a focus on making global IDs more stable when people wear similar clothing or overlap.

Next, I plan to validate gallery update strategies against contamination using the existing annotations, and examine how detection quality and feature selection affect identity assignment. This work is planned and is not presented as a completed result.
