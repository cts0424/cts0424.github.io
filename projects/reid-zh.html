01 / PROBLEM

研究問題

當同一人暫時離開畫面、重新出現，或出現在另一台攝影機時，系統能否維持一致的全域 ID？

單鏡頭 tracker 主要處理相鄰影格的短期關聯；跨片段與跨鏡頭的身分判斷則需要比較人物外觀特徵。相似衣著、遠距離、遮擋及人物重疊，會使這項判斷更困難。

本專題也研究 Open-set 情境：畫面中的人可能不在既有 Gallery 中，系統必須判斷是沿用已知 ID，還是建立新 ID。

02 / SYSTEM

已實作的系統流程

影片／串流YOLO 人物偵測ByteTrack 局部軌跡CLIP-ReID 特徵Gallery 全域 ID
  • 以 YOLO 偵測人物框，再由 ByteTrack 將同一鏡頭中連續影格的人物連成局部軌跡。
  • 從需要判斷身分的影像裁切中抽取 CLIP-ReID 特徵，與 Gallery 中的身分特徵比對，決定沿用全域 ID 或建立新 ID。
  • 已建置雙鏡頭共用 Gallery 的流程，讓兩路影像使用同一套全域 ID；單鏡頭追蹤評估與跨鏡頭功能驗證分別處理。

系統曾嘗試 OC-SORT、不同頻率的 Re-ID 更新及 ArcFace 輔助檢查；下方僅列出已有明確實驗範圍與結果的分析。

03 / TRACKING EVALUATION

Local 與 Global ID 評估

以同一次執行產生的 ByteTrack local ID 與加入 CLIP-ReID v2.5 的 global ID，對照 2,661 幀人工標註資料。Global 在身份關聯指標上提升，但因部分偵測未進入全域輸出，偵測準確度下降。

單鏡頭影片：2025-12-04_06-32-41.mp4；TrackEval 對照 verified GT。Global 比 Local 少輸出 2,816 個框（12.70%），因此這是實際系統輸出的比較，並非相同偵測框下只更換 ID 的實驗。腳本指定 yolov5s.pt，實際載入 Ultralytics yolov5su.pt；GT 中 visibility=0 的標註也參與計分。此結果不能直接代表跨鏡頭準確率。

05 / GALLERY

重疊人物與 Gallery 污染

人物重疊時，另一人的影像可能混入裁切結果。 如果用這張影像更新 Gallery，原本的身分特徵就可能逐漸偏移。

06 / NEXT

目前方向

延續跨相機人物追蹤與 Open-set Re-ID，優先改善相似衣著和人物重疊時的全域 ID 穩定性。

下一步將以現有標註資料驗證 Gallery 抗污染更新策略，並檢查偵測品質、特徵選取與身分指派之間的關係。這些是後續工作，尚未列為已完成成果。
