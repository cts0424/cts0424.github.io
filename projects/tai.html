01 / CONTEXT

Project Goal

Build a trustworthy AI assessment system that helps users evaluate an AI system across several indicators through questionnaires and receive understandable results and suggestions for improvement.

The system is based on 11 trustworthy AI indicators. Users can create assessment projects, complete and save questionnaires, review past responses, and receive reports with indicator scores, visualizations, and improvement suggestions. Administrators manage questionnaires, questions, and response options so the system can support different versions, question types, and indicator categories. Reports incorporate LLM-generated suggestions, and integration with the ICCC platform is a project goal.

This was a team project for a software engineering course. This page focuses on my backend work: database modeling, authentication and access control, project and questionnaire APIs, response processing, report data, and LLM integration. The frontend and the overall system were developed by the team.

02 / WORKFLOW

How the System Works

User | Complete an Assessment

01Sign in and create a project
02Choose and complete a questionnaire
03Save and submit responses
04Review reports and history

Users can save a questionnaire in progress. After submission, the system generates indicator results and a report, and keeps the responses for later review.

Administrator | Manage Assessment Content

01Sign in as an administrator
02Manage questionnaires and versions
03Maintain questions, options, and indicators
04Make questionnaires available to users

When a questionnaire changes, existing responses remain linked to the version that users completed, so past reports can still be interpreted correctly.
