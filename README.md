# 個人作品集初版

靜態 HTML/CSS/JavaScript，適用 GitHub Pages。`index.html` 為預設英文首頁，`index-zh.html` 為中文首頁；兩個專案頁也各有英文及 `-zh.html` 中文版本。頁首可切換語言。

## 部署
1. 建立名稱為 `<你的 GitHub username>.github.io` 的 public repository。
2. 將本資料夾內的所有檔案（包含 `index.html`、`index-zh.html`、`assets/`、`projects/` 和 `.nojekyll`）上傳至 repository 根目錄。
3. 至 Settings → Pages，選擇 Deploy from a branch、`main`、`/(root)`，儲存。
